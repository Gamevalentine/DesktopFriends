# 更新日志

## v1.4.0 — 桌面体验与小组件能力升级

发布日期：2026-08-23

### 主要更新

- 桌面端悬停检测改为读取 Live2D 模型的实际可见像素。透明区域继续保持鼠标穿透，工具栏只在指针真正进入模型后出现。
- 工具栏会根据模型实际位置浮动，并完善锁定、置顶等操作说明。
- 对话记录拆分为独立窗口，避免透明桌宠窗口裁切长内容；支持清空以及 JSON、TXT 导出。
- 新增独立的时钟、天气和待办桌面小组件窗口，默认使用无背景透明样式，可移动、置顶、关闭或移除。
- 小组件采用“组件即能力”机制：启用某类组件时动态注册对应 Agent Tool，移除最后一个同类组件时自动撤下。
- 天气和待办状态支持跨窗口同步，Agent 可以读取天气组件中的实时数据。
- 移动端同步接入动态小组件工具与共享天气状态。

### 时间表文档

- 将时间表（Timemap）与本地心跳提升为项目核心亮点，强调从被动聊天到主动陪伴的产品方向。
- 补充自然语言建表、Agent 自主规划、五类管理工具、条目生命周期、跨天规则和本地持久化说明。
- 明确本地心跳每 60 秒检查一次，检查本身不消耗 LLM Token，到期执行时才请求模型。
- 补充当前 Android 接入范围以及后台挂起限制，避免把应用内时间表误当作系统级闹钟。

### 精简与兼容性

- 移除小智语音与 OpenClaw 集成以及相关服务端桥接代码，聚焦桌宠、Agent、时间表和小组件体验。
- 本次版本统一应用、共享包、Android 与 Tauri 内部版本号为 `1.4.0`。

### 已知提示

- Android 后台保活仍在开发中，应用被系统彻底挂起或关闭时无法保证时间表准时触发。
- 前端生产构建仍会提示部分 bundle 超过 500 kB。
- Rust 依赖 `block v0.1.6` 存在未来版本兼容警告，不影响当前构建。
