# 快速开始

本指南将帮助你在 5 分钟内启动 DesktopFriends 桌面宠物。

## 准备工作

你需要：
- 一台安卓手机（Android 7.0+）或者电脑
- 一个 LLM API Key（OpenAI / Claude / DeepSeek 任选其一）

## 步骤 1：安装应用

从 [下载页面](/download) 获取最新的 APK 文件，安装到你的安卓手机上。

详细步骤参见 [安装 APK](/guide/installation)。

## 步骤 2：配置 AI

1. 打开应用，点击右上角 **设置** 按钮
2. 在 **AI 配置** 中：
   - 选择服务商（推荐 DeepSeek，性价比最高）
   - 输入 API Key
   - 点击 **测试连接** 确认配置正确
3. （可选）自定义宠物名称和人设

::: tip 本地 AI
如果你在电脑上运行了 Ollama 或 LM Studio，选择"自定义"服务商，输入本地 API 地址即可使用。
:::

## 步骤 3：开始对话

返回主页，在输入框中输入消息，即可与宠物对话。宠物会：
- 逐字流式输出回复（Markdown 格式）
- 自动选择合适的表情和动作
- 在内心思考是否需要回复

## 步骤 4：体验主动提醒

试着对宠物说：

> 下午 3 点提醒我喝水。

宠物会调用时间表工具创建计划。你还可以继续问“今天有什么计划？”或“把提醒改到 3 点半”。应用运行期间，本地心跳每 60 秒检查一次；到期后宠物会主动执行，而不是等待下一条用户消息。

::: tip 每日计划
说“每天上午 9 点跟我说早安”会创建 `daily` 条目；普通提醒默认是仅当天执行的 `once` 条目。
:::

详见 [时间表系统](/guide/timemap)。

## 步骤 5：探索更多功能

- **时间表**：让宠物自主规划当天的问候和休息提示
- **小组件**：移动端进入编辑模式添加组件；桌面端从模型工具栏打开独立组件窗口
- **多宠物联动**：连接同一局域网的中继服务器，让多个宠物互相聊天

## 多设备联动（可选）

如果想让多台设备上的宠物互相交流：

1. 在任一设备的设置页中一键启动服务器
2. 其他设备搜索并连接到同一服务器
3. 开启"自动对话"，宠物会自动互相打招呼

详见 [多设备联动](/guide/multiplayer)。
