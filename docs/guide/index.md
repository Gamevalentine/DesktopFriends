# 简介

DesktopFriends 是一个开源的 Live2D 桌面宠物应用。它不仅能通过大模型与你对话，还通过时间表和本地心跳获得“时间感知”，可以自主安排计划并在合适的时间主动陪伴你。

## 主要特性

### 🤖 AI Agent 系统
- 自研 ReAct 引擎，从零构建的智能体
- 支持 OpenAI / Claude / DeepSeek / 自定义 API
- 流式响应，逐字输出到聊天气泡
- Markdown 渲染（粗体、代码块、列表）
- Function Calling 控制宠物表情和动作
- 认知系统（内心独白 + 选择性回复）
- 客户端直接调用 LLM API，无需后端中转

### 🎭 Live2D 支持
- 支持加载自定义 Live2D 模型
- 流畅的动画和表情切换
- LLM 增强的模型分析器，自动识别动作含义

### ⏰ 时间表系统
- 用户可以直接说“下午 3 点提醒我喝水”
- Agent 也能自主创建问候、休息提示等每日计划
- 本地心跳每 60 秒检查一次，检查过程不消耗 LLM Token
- 到期时才唤醒 Agent，并结合宠物人设主动执行
- 支持查看、修改、删除、每日重复和一次性条目

[详细了解时间表系统 →](/guide/timemap)

### 📱 多设备联动
- 手机端与电脑端均可开启房间（中继服务器）
- 局域网自动发现，搜索房间（mDNS）
- 信息实时同步并共享

### 🧩 小组件系统
- 时钟 / 天气 / 待办按启用状态动态注册 Agent 工具
- 桌面端使用独立透明窗口，移动端使用可编辑网格
- 天气与待办实时状态可供 Agent 读取

## 工作原理

```
┌─────────────────┐     Socket.IO      ┌───────────────────────┐
│   中继服务器      │ ◄───────────────► │   应用端 (手机或者电脑)   │
│  Relay Server   │      WebSocket     │   Live2D + AI Agent   │
└─────────────────┘                    └───────────────────────┘
                                               │
                                               │ 直接调用
                                               ▼
                                       ┌─────────────────┐
                                       │   Cloud LLM API │
                                       │ OpenAI/Claude/  │
                                       │ DeepSeek/Custom │
                                       └─────────────────┘
```

1. **应用端**：手机/电脑运行 Live2D 应用 + AI Agent 引擎
2. **AI 调用**：客户端直接调用 LLM API（在设置中配置 API Key）
3. **中继服务器**：仅用于多宠物间的通信，不经手 AI 请求
4. **通信**：通过 Socket.IO 在局域网内实时通信
